**Принципы, заложенные в код проектов:**
* Использование штатных механизмов платформы.
* Разделение клиентского и серверного контекста.
* Оптимальные пакетные запросы с временными таблицами, индексацией и параметрами виртуальных таблиц.
* Контроль остатков по новой методике и явные управляемые блокировки.

## 🛠 Сводный стек репозитория

* **Платформа:** 1С:Предприятие 8.3 (Управляемые формы, функциональные опции, параметры сеанса, роли).
* **Регистры и учет:** Регистры накопления, регистры сведений, регистр бухгалтерии, регистр расчета.
* **Аналитика:** СКД (вычисляемые поля, ресурсы, параметры, условное оформление, диаграммы).
* **Интеграции и файлы:** Чтение Excel и временное хранилище, JSON / XML, HTTP-сервисы (REST) и Web-сервисы (SOAP).
